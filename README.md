# superstore-power-bi-sales-analysis
Power BI analysis of Superstore sales, profit, quantity, discounts, and category performance.
## Project Overview

This project analyzes the Superstore dataset using Microsoft Power BI to identify key sales, profit, quantity, discount, and category performance insights.

The goal of this project is to transform raw retail data into meaningful business insights through interactive data visualization and dashboard reporting.

## Objectives

- Analyze overall sales performance
- Analyze total profit and profitability
- Identify the highest-performing product categories
- Analyze quantity sold
- Evaluate discount performance
- Identify important business trends and patterns
- Create an interactive Power BI dashboard

## Key Performance Indicators

- Total Sales: $2.30M
- Total Profit: $286.40K
- Total Quantity Sold: 38K
- Average Discount: 1.56K
- Highest-Performing Category: Technology

## Key Insights

- Technology was the highest-performing category.
- Total sales reached approximately $2.30M.
- Total profit was approximately $286.40K.
- The dashboard provides an overview of sales, profit, quantity, discount, and category performance.
- The analysis demonstrates how business data can be transformed into actionable insights.
